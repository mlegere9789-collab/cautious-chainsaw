# Medical evidence: source ledger

Written 2026-11-14 by the planning step of the medical workstream (OA12). It says which texts are local, which are to acquire, on what rights, and with which hash. The machine copy the validator reads is `sources.json` (same folder); `tools/bt/medical/make_sources.py` wrote both once. **The ledger at the end of this file is append-only**: whoever puts a file under `tmp/library/medical/<source id>/` appends one table row (11 cells) with a shell `>>`, and the validator then accepts quotes from that file. A row of this file is never edited or deleted.

## 1. Rules

* **Reachable hosts only**: archive.org (download `https://archive.org/cors/<identifier>/<file>`), gutenberg.org, www.loc.gov, tile.loc.gov, cdn.loc.gov, www.nps.gov, www.npshistory.com, chroniclingamerica.loc.gov, catalog.archives.gov. hathitrust.org and ehistory.osu.edu answer with their own bot block: blocked, not retried. At most one request a second; no logins, no CAPTCHAs, no bot-block circumvention.
* **Rights.** Books and pamphlets published in the United States before 1929 are public domain; the OCR text is machine output of the scan and carries no separate claim. Official Records, National Park Service texts and Surgeon General publications are United States government works. A file whose rights are not clear is not downloaded; the owner decides (section 5).
* **Classes** (the validator uses them): `official-report`, `official-history`, `period-manual`, `memoir-primary`, `contemporary-print`, `institutional-history`, `regimental-history`, `nps-report`, `photo-record`, `reference-secondary`, `lead`. A `lead` source (Wikipedia, forums, blogs, marker-transcription databases, auction and commercial pages, the museum and magazine pages the PDF cites without a primary basis) can support only an open gap row; `reference-secondary` supports at most an inferred row; Law 4 is not negotiable.
* **Edition.** Every row names the edition of the printing it quotes. The edition column below is what was read on the title page, or says it was not read. The archive.org date field is a catalogue date, not an edition statement (two items below show the difference).
* **Hash.** `sha256` of the file as downloaded; for every archive.org text the md5 was also compared with the md5 of the archive.org record and equal. A quote is valid only while the file hash is the recorded one: the offsets are character offsets into that exact file.
* **Extract once.** Check this file and `tmp/library/medical/` before downloading; a text is downloaded once and read from disk by every group.

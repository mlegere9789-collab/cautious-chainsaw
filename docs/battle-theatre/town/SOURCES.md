# Source ledger: the town and buildings evidence pass (OA10)

Written for the evidence files `docs/battle-theatre/town/evidence/<group>.jsonl` and read by `tools/bt/town/validate_evidence.py`, which takes the source classes, the local text paths, the hashes and the page model of every row from the tables of this file. Seeded by `tools/bt/town/build_sources.py` from the local library; the group passes append the sources they acquire at the end of the file (section 10).

## 1. How a row of an evidence file uses this ledger

- `source` is an id of the first column. `class` decides what the source may do: **primary** (made in 1863-1869 by a witness or an official actor, or a page of a paper of 1863), **official** (a Park Service, Library of Congress or National Archives record), **book** (any later published account, public domain), **lead** (a web page, an encyclopaedia, a forum, a blog, an aggregator, the owner's plan itself: it may point to a source to read, it can never make a claim `documented` or `inferred`: the validator refuses a lead as the source of such a row).
- `text` is the repository-relative path of the local text the quote is matched in. A path with `{part}` is a family of texts (the weekly papers, the newspaper pages): the row names the part (for the papers the issue date, for the newspaper pages `<lccn>/<date>/ed-1/seq-<n>`). `-` means there is no local text: the source can be cited only as an image reading (`image_ref`).
- `pages` is the page model: `markers` (the text carries `=== PAGE n ===` lines; the row's `page` is checked against them), `or27` (Official Records: the row's `part` is a record id of `docs/battle-theatre/library/or27_index.json`; offset and page are checked against the record), `none` (the text has no page marks: `page` is the printed page as read, or null with `page_note`; the offset is the locator).
- Offsets are character offsets into the file decoded as UTF-8 with `newline=''` (the convention of `tools/bt/or27_lib.py`).
- A row of a later date than the battle describes a later state: the validator will not let it make an 1863 value `documented` without a `continuity` citation (a statement that the feature is unchanged since 1863).
- Public sources only, one request per second (five seconds for www.loc.gov), no login, no CAPTCHA, no bot-block circumvention; a refusal is recorded as blocked and never worked around.

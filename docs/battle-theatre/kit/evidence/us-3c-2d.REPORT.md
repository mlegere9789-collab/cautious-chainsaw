# Kit evidence report: us-3c-2d

Evidence file: `us-3c-2d.jsonl`. Register proposals: `GOVERNANCE/horde/ws-kit/proposed-register/us-3c-2d-01.md` to `-03.md`. An earlier run had left only a scratch folder (report extracts) and no evidence file; every line was written in this pass.

How the file was made. A builder in `tmp/kit-us-3c-2d/` (`kb.py`, `build.py` and the packages `p1_table.py` to `p6_gaps.py`) locates each quote in the text through the evidence library, so offset, report id and (for the Official Records and the state volumes) printed page come from the tool. The figures that the OCR scrambles (the rows of the return of casualties, the 4 July abstract row, three regimental tables of loss) were read from the scan at 250 to 380 dpi and added up against the printed totals. A second matcher (`tmp/kit-us-3c-2d/verify_quotes.py`, which does not use the library's locate function) re-read 202 quotes at their offsets by letters and digits: one failure, line 0156 (Humphreys's "5,000 strong"), because the quote runs over a page break and the running head of the OCR sits inside it; the library's own matcher accepts it. `python -I tools/bt/kit_overrides.py compile --dry-run --group us-3c-2d`: 6 operations, 24 entries unapplied (23 routed to the verified tables by design, 1 to review: Sharps of unspecified pattern, 0185). `python -I tools/bt/kit_verified.py build` was run once through `tools/horde/bench.sh` (no other run was active): of the 23 units 12 are `verified` and 11 `partly`.

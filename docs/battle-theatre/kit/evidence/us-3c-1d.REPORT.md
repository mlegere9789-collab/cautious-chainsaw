How the file was made. A builder in `tmp/kit-us-3c-1d/` (`kb.py`, `build.py` and the packages `p1_table.py` to `p10_gaps.py`) locates each quote in the text through the evidence library, so offset, report id and (for the Official Records and the state volumes) printed page come from the tool and not from hand. The nine texts declared in the file (Stevens and eight regimental histories; the library note lists them) have no page model: the checker warns `PAGE_UNCHECKED` and each line's note gives the printed page, read from the running heads of the OCR text (corrected where a head is misread) and, for two tables of Craft, from the scan. The figures that the OCR scrambles (the rows of the return of casualties, the abstract rows, Berdan's table of losses, Craft's return of 30 June and Madill's roll-call) were read from the scan at 300 to 450 dpi and added up against the printed totals. A second matcher (`tmp/kit-us-3c-1d/verify_quotes.py`), which does not use the library's locate function, re-read every one of the 424 quotes at its stated offset by letters and digits: no failure. `python -I tools/bt/kit_overrides.py compile --dry-run --group us-3c-1d` (writes nothing) runs: 28 operations, 42 entries unapplied, 24 of them routed to the verified tables by design (the commanders) and 18 to review (see the catalog request note).

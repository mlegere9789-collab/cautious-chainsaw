- ANIMATION publishes `src/anim3d/index.mjs` (clip library, state machine driven by unit activity + drill clocks, per-figure phase offsets, vertex-animation-texture or skinning data layout) and `data/anim3d/*`; consumes FIGURES' skeleton definition (agree on `data/figures3d/skeleton.json`: FIGURES writes it first, within your first hour of work; ANIMATION writes against that spec and adapts).
- FX publishes `src/fx3d/index.mjs` (particle/volume systems: musketry smoke, cannon smoke, muzzle flash, dust, shell bursts, fires; spawn from ANIMATION's fire events via the event interface `onFire(unitId, figureIdx, t, weaponKind, position, direction)`).
- AUDIO publishes `src/audio3d/index.mjs` (spatial mixer: per-event delay, spreading, absorption, doppler, reverb) consuming the same fire events plus drill/voice/signal events from the history layer.

# town-churches-EG-06: The yellow circle of the Sanborn plan of 1886 and the lantern of the German Reformed church

| Field | Content |
|---|---|
| ID | town-churches-EG-06 |
| Requirement IDs | R12, OA10 |
| Category | inference from a symbol that the key does not explain |
| Description | A round yellow (frame) symbol of 8 to 10 ft stands inside the brick footprint near the front gable of four churches: Christ Lutheran (rows 0093), Catholic (0126), German Reformed (0189) and St. James' (0231); the Presbyterian and the United Presbyterian churches show none. The key of the plan does not explain the circle. For the Catholic church it agrees with the Roman cupola that Reily describes (documented, row 0125); for the German Reformed church it agrees with the open lantern on the ridge in LOC 2012647712 (row 0188). For Christ Lutheran and St. James' the cupola is an inference from the symbol alone. |
| Why literal 100% is not possible or blocked | The plan is of 1886; no photograph or text of 1863 shows or describes the tower of Christ Lutheran or St. James'; the key is silent. |
| Evidence searched | The Sanborn key sheet and the four church crops; Reily 1885; the 1863 photograph; the weeklies and the 1886 history (no description of any tower). |
| Autonomous substitute applied | None. |
| Strongest evidence-based reconstruction | A cupola or bell turret at the front gable drawn on the four churches, marked inferred where only the circle supports it (Christ Lutheran, St. James'). |
| Confidence tier | documented (Catholic cupola), inferred (Reformed lantern, Christ Lutheran, St. James') |
| Competing values | A cupola against no tower for Christ Lutheran and St. James'. |
| Product marking | Inferred marker on the two churches without a second source. |
| Visual and audio impact | The skyline of the town. |
| Review status | internal review only (DEC-006: no public review label) |

| Agent recommendation | Draw it, marked inferred, because the same symbol agrees with a documented cupola and a photographed lantern. |

## Method (what was run)
1. Every citation was cut from the raw local text by an anchor pair (start text, end text) through a builder that refuses a quote it cannot find; a quote that crosses a page break is split in two (the running head stands between them in the raw text). Official Records: `tools/bt/or27_find.py` logic (normalised view without running heads); state volumes: `tools/bt/statevol_find.py` logic; library and NPS texts: the normalised search of `tmp/fence-2/scripts/corpus.py`. The saved NPS web page of Jennie Wade (`tmp/library/web/retry/F-052`) and the layout version of the Leister HSR text are cited by their file paths and sha256.
2. Independent mechanical checks on the final file: `scripts/validate.py` cuts the span `[offset_start, offset_end)` out of the raw file named by `local_path`, compares it (whitespace and hyphen tolerant) with the quote and checks the sha256 of the text: **36 rows, 319 citations, 0 problems**. `scripts/verify_or.py` re-finds every Official Records quote by text search with `tools/bt/or27_find.py` (not by offset) and compares report id, printed page and offsets: **172 OR citations, 0 problems, 0 page differences**; the same script compares the 51 lines of this shard in `horde/OR-RECHECK/results.jsonl` (found yes): 19 agree exactly, 31 are contained in a widened or merged quote of the same report, 0 disagree, 1 is the Hall quote of the shard row that was withdrawn (S-032: a 1 Jul passage).
3. The builder is reproducible: `python3 -I tmp/fence-2/scripts/r2_assemble.py OUT` rebuilds the file from the round-1 baseline (`tmp/fence-2/backup/`) plus the per-row patches `r2_a.py`, `r2_b.py`, `r2_c.py`.
4. Not run: any browser or render check (none needed); the web pages of the blocked hosts; the page image of OR27-1 p.855 ("about G a. m.", read 6 by two other reports); the Pennsylvania State Archives claims.

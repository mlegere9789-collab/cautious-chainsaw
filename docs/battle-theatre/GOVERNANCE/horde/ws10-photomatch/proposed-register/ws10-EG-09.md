# ws10-EG-09: Q16 catalogue was incomplete: records dated only "between 1861 and 1865" had been dropped

| Field | Content |
|---|---|
| ID | ws10-EG-09 |
| Requirement IDs | R12, Q16 |
| Category | process / evidence missing |
| Description | The first catalogue run kept only LOC records whose date field contains 1863. LOC catalogues many Brady/Gardner battlefield prints as "photographed between 1861 and 1865", among them the print the NPS cites as a Brady photograph of July 1863 (ppmsca 32840, record 2012647706). 18 such records were added (catalogue_additions.json) with their images. One of them (2012647845) proved by image match to be the staged Weaver photograph of 11 November 1863 and was taken out of the July test; another (2012647846) is a White Studio copy whose original date is unknown. 47 further search results stay out with a reason each (1865 views, the November dedication, portraits, other places). |
| Evidence searched / action | Open JSON search of the cwp collection (174 results, two pages); records outside the cwp collection (for example LC-DIG-ppmsca-18947, Gibson, which the NPS first-day report cites, and the negative LC-B815-273 of the Evergreen lodge roof view) were not searched. |
| Confidence tier | documented (what LOC states), inferred (the July 1863 subject of the added records) |
| Visual and audio impact | None directly; the photo-match registry now covers 127 records. |
| Product marking | Added records carry added_reason and date_status |

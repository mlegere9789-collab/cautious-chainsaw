# ws10-EG-06: Q16 titles/dates in LOC records partly rest on Frassanito

| Field | Content |
|---|---|
| ID | ws10-EG-06 |
| Requirement IDs | R19, Q16 |
| Category | evidence conflict |
| Description | LOC records such as 2018666310 state 'Title and exact date from Frassanito (1975)'. The catalogue records only LOC's own statement of date and title and tags it as LOC-stated; Frassanito's text and images are not used. Under the Law (no lead-only support) a date taken from that note stays 'catalogued', not 'documented'. |
| Evidence searched / action | Find a non-lead source for exact dates (diaries, newspapers, Gardner's captions). |
| Confidence tier | inferred |
| Visual and audio impact | Dates in the catalogue are LOC catalogue values. |
| Product marking | Photo-match report lists the assumption beside every pose |
| Review status | internal review only (DEC-006: no public review label) |
| Owner decision requested | See Evidence searched / action |

Every quote is cut from the saved source text and is found again by `scripts/verify_extracts.py`. "State date" is the date the described feature state refers to: a modern survey describes modern or reconstructed features unless the passage itself says otherwise, and nothing dated later than July 1863 may be used as an 1863 profile. Page numbers are PDF page indexes of the file as served (printed page in brackets where the page shows one). Use for the July 1863 scene: `direct` = the passage states an 1863 (or earlier, still standing) condition; `indirect` = a later, modern, reconstructed or replanted state, usable only as a marked inference; `none` = a feature that did not exist in July 1863 and must never be drawn in the 1863 scene. Tier: `documented` = the report states it as fact (official secondary source; its own 1863 basis is given where the passage names it); `inferred` = the report itself hedges or reports conflicting evidence.

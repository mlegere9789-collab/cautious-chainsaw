# EG-LIFE-0206: Hancock's burial table of 2-5 July: CLOSED by a page image on 2026-11-16 (not to be registered)

| Field | Content |
|---|---|
| ID | EG-LIFE-0206 |
| Requirement IDs | R22, R21, OA11 |
| Category | evidence missing / access (closed) |
| Description | The numbers of the dead buried by the Second Corps from 2 to 5 July (Hancock's report of 17 July 1863, signed by the acting corps commander, OR27-1 printed p. 378) are in a table that the local text of the volume prints as run-together cells without its column headings, with one damaged digit and the first date misread. |
| Why literal 100% was blocked | The local text did not keep the columns or the headings; the first run of group us-2c read the totals by the arithmetic of the printed figures (inferred) and registered the gap. |
| What closed it | The page image of leaf 401 of the volume (PDF page 402 of the local copy `tmp/kit-plan/or27-pdf/cu31924077699761.pdf`) was read by eye at 220 and 450 dpi on 2026-11-16. It prints "from July 2 to 5, inclusive" (the local text has "July 3 to 5") and a table with the headings Forces, Officers, Enlisted men, Total: Union 18, 369, 387; Rebel 60, 1,182, 1,242; Total 78, 1,551, 1,629 (the local text has 869 for 369; the digits of 18 and 60 are blurred in the print and agree with the sums). Remark: "One female (private), in rebel uniform." |
| Result in the evidence | Row us-2c-R275 (the table) is documented, with `ocr_repairs` (basis page_image) for "869" and "July 3 to 5"; row us-2c-R086 (the sentence that introduces it) has the window of 2 to 5 July; the open gap row us-2c-R258 is withdrawn (its id is not reused). |
| Evidence searched | Group us-2c: the local text of OR27-1 p. 378 (hit_ambiguous), then the page image (read). |
| Confidence tier | documented (the corps buried 387 Union and 1,242 Confederate dead from 2 to 5 July, 1,629 together); the regiments' own figures are separate rows (84 Confederate dead by the 42nd New York, 37 by Carroll's brigade, 4 officers and 38 men of Carroll's brigade and 37 Confederates by the pioneers) |
| Competing values | none (the totals are consistent by their own sums); the dates "July 3 to 5" of the local text are a digit error of the print's OCR, not a competing source |
| Product marking | none needed for the table: documented. |
| Review status | internal review only (DEC-006: no public review label); the digits of the page image were read by one reader |
| Status | CLOSED: not to be added to register/ (kept so that the number EG-LIFE-0206 is not reused) |
| Owner decision and date | none required |

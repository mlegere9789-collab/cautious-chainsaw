# Request from bt-units (group us-1c-1d-art): section headings of docs/battle-theatre/library/statevol_index.json

What: the section index of the state volumes (`library/statevol_index.json`, built by `tools/bt/statevol_index.py`) names a section by the first heading the tool found. In five sections the text that the Union I Corps group needs lies under a heading that names another unit, and in one the author list is short. The group file `undrawn/us-1c-1d-art.jsonl` cites these sections by id (the checker takes the id from the index), so a card that prints the section heading as the source line names the wrong unit. Found while reading for the group; each row was checked against the text at the offsets the records cite.

Why it matters (Law 4 and the card's source line): a citation whose section heading names another unit confuses a reader who checks the quote. The checker finds every quote at its exact offset and no record of the group file is wrong. One search of mine missed `NY3-S024` for that reason (the index heading is Battery G); it was found in the closing pass and is now read (the gap record of the batteries' strength says so).

The exact change wanted (not mine to make): split or re-title the six sections so that each heading names the unit whose text it holds, or add a `contains` list of unit labels to each section; rebuild `statevol_index.json`. No record of `us-1c-1d-art.jsonl` needs to change when the ids stay the same; if ids change, tell bt-units (this group) so that the quotes can be re-checked with `python3 -I docs/battle-theatre/history/undrawn/tools/check_undrawn.py us-1c-1d-art --complete`.

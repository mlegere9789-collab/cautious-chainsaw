# bt-oob-kit / us-5c: library ledger (eleven texts fetched, seven already on disk)

Written 2026-11-24 by workstream bt-oob-kit. Public-domain books of 1865 to 1915, openly readable on archive.org. The download path `https://archive.org/download/<id>/<id>_djvu.txt` redirects to a storage host the session proxy refuses (403), so each item was fetched once as the full-text page `https://archive.org/stream/<id>/<id>_djvu.txt` (one request per item, at most one a second, about 40 requests of the catalogue search `advancedsearch.php`) and the text between `<pre>` tags was saved unchanged apart from the unescaping of HTML entities. No credential, account or purchase. No host was refused except the storage host named above. Local copies are in `tmp/kit-us-5c/lib/<id>/<id>_djvu.txt` (scratch; re-fetch by the url, and note that the sha256 in the evidence file pins this extraction, not archive.org's own text file).

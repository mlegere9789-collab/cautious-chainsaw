## How to validate a line
1. Open `citation.local_path` (relative to the repository root), find the marker `=== PAGE <pdf_page> ===`, normalise whitespace. `quote_mode` sentences or anchors: the quote is a verbatim substring. `quote_mode` cleaned: the letters and digits of the quote equal those of `source_text_excerpt` (spacing and punctuation ignored; for sources with a lost-glyph defect the groups ti, tt, tf, ft, tl, ff, or f followed by i, f, l, are ignored on both sides); `ocr_corrections` lists every (saved, fixed) pair in the extract record. `context_quote` (when present) is a second verbatim passage of the same source (page `context_pdf_page`, usually the entry heading or a list head) that carries a name, date or number the claim needs; the claim is supported by the quote and the context quote together, and every number of the claim stands in one of them. `scripts/verify_extracts.py` does all this: 715 extracts, 0 problems, 0 warnings, quotes and context quotes matched against the saved text; `text_sha256` is the hash of the text file (variant raw = content-stream order, for the two-column reports).
2. `source_class` is a National Park Service report or page (United States government work): non-lead, secondary.

## What
The staging packer's copy audit (`tools/bt/pack_theatre.mjs`, `AUDIT_RE`) now also catches a tool path that does not start with `tools/` (for example `app/tools/...`) and build-stamp keys. It reports these lines in files you own. Each one says how a shipped file was made, which GOVERNANCE/FINAL-ACCEPTANCE.md ("Copy audit rules": no "generated" ... as the way the site was built, in any shipped file, JSON data and comments included) and rule 6 of the horde rules forbid. The same kind of note was already reworded in `kit/*.json` and `app/data/placement*.json` on 2026-11-11.

## Exact change asked
Change the text at its source (the generator, then regenerate the data file so the two agree and your tests stay green), not the data file by hand:
1. clips.json: drop the `generated_by` field, or rename it to a field that does not say how the file was made (for example `"tables": "anim3d drill tables"`); the reader does not use it (check `grep -rn generated_by docs/battle-theatre/app/src docs/battle-theatre/app/tests`).
2. skeleton.json: same for `generated_by`.
3. measurements.json `_doc`: delete the sentence "Generated by app/tools/build-audio3d-data.mjs.".
4. weapons-sound-map.json `_doc`: "Weapon (kit id) -> sound id, following src/audio3d/catalog.mjs. Four sounds ..." (no "generated by <tool>").
5. sources.json: rename `"generated"` to `"as_of"` (a date of the ledger, not a build stamp) and update whatever reads it.
6. woods.mjs comment: "Input: data/audio3d/woods-mask.json (the 1863 woods layer, a reconstruction from the Warren survey of 1868-69, rasterised)".

Also for your judgement (not failing hits; the packer only counts these words and prints them as "internalWordsForReview"): `workstream` in app/src/history/cavalry.mjs line 1 and app/src/structures/index.mjs lines 14, 28, 40 (one is a console.warn text: "workstream 6 lists not built"), `horde` in app/src/structures/artillery.mjs and works3d.mjs and app/data/audio3d/gaps.json, "film-grade round N" in the figures3d module headers. They name the working process, not a tool.

When done, append `-- handled: <what was done>` to this note with a shell `>>`.

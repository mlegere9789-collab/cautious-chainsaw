# EG-MED-WW-05: The scalp tables of 1870 and 1883 differ, and the text under the 1870 table disagrees with its own table

| Field | Content |
|---|---|
| ID | EG-MED-WW-05 |
| Requirement IDs | OA12 (accurate field hospitals, battle trauma and period-accurate treatment); PDF B.8.5; gate Q26; Law clauses 3, 4 and 7 |
| Category | source conflict and internal discrepancy |
| Description | Table V of the first surgical volume (1870, page 91) names the missile in 4,002 gunshot wounds of the scalp (round musket ball 384) and leaves 3,737 unnamed; Table CXXI of the third volume (1883, page 696) gives for the scalp round or musket ball 521 and 3,600 not ascertained (the totals agree: 7,739). The 1870 text under its table says that 72.6 per cent. of the named wounds were by small-arm missiles; the table's own small-arm items (2,612 + 384 + 2 + 94 + 25 = 3,117) are 77.9 per cent. of 4,002. |
| Why literal 100% is not possible or blocked | The record does not state it, or the text is not available to this project (Law cl.3); nothing is invented to fill it. |
| Evidence searched | The OCR of both scans of the first volume and the first issue of the third; the page image of Table CXXI. The page image of Table V was not looked at. |
| Autonomous substitute applied | None applied; both readings are rows of a conflict set (cs.scalp-missile: med.wounds-weapons.102 and .175); the discrepancy of the 1870 text is row .267. |
| Strongest evidence-based reconstruction | The scene cannot show the scalp share to a viewer as a record; it draws the missile of a scalp wound from the chosen basis and marks it. |
| Confidence tier | documented (each reading as printed); open gap (which figure of the text is the History's) |
| Competing values | Round or musket ball for scalp wounds: 384 (1870) against 521 (1883); small-arm share 72.6 (text of 1870) against 77.9 (the table's items). |
| Product marking | The scene or card carries the tier mark and, for an open gap, the gap marker with this id. |
| Visual and audio impact | the sampling table (scalp wounds) |

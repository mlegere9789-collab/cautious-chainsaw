# ws-world-EG-MON-01: The year each later memorial was put up is not in the site's data

| Field | Content |
|---|---|
| ID | ws-world-EG-MON-01 |
| Requirement IDs | OA01; R14 (no modern object in the 1863 scene), R22; Law clauses 3, 4 and 7 |
| Category | evidence missing |
| Description | The site's Monuments list (512 entries, app/data/site-memorials.json, copied read-only from the site) gives a name, the persons or units remembered, a place line, a position, a side, a group and a park number. It gives no year of dedication or erection for any entry. The theatre therefore cannot place a memorial anywhere on the scrubber, and does not try: the layer is off by default, every mark and card says "later memorial" and "Put up: open gap", and no memorial is ever drawn as an object of the 1863 scene at any time. |
| Why literal 100% is not possible or blocked | The year is not in the data the owner told the theatre to reuse (OA01 is a read-only reuse of the site's data). A year for each memorial has to come from a non-lead source that names that exact memorial. That source exists in part (see below) but has not been matched to the 512 entries name by name, and a match made on a similar name would be a guess (Law 4). |
| Evidence searched | The site's data (all 512 records: no year field). Library text of Bachelder, Gettysburg: What to See, and How to See It (1889), pages 21-22 (BACH-WHATTOSEE-1889): it says that when the first edition was compiled "no material changes had been made on the field" and that in 1889 "the position of each command is being marked by monuments" along avenues built since: that a memorial is later than the battle rests on this and on what a memorial is, not on a per-memorial year. NPS Cultural Landscapes Inventories (Pickett's Charge Battlefield, Emmitsburg Road Ridge Battlefield; extracts by bt-web under GOVERNANCE/horde/ws-web/nps/extracts/monuments-later.md) print chronology lines of the form "CE <year> Memorialized Monument/marker is erected: <name>" for some memorials (for example North Carolina State Monument 1929, Virginia Monument 1912-1917, Florida State Monument 1963, 14th Connecticut position markers 1884). Not yet matched to the 512 names. |
| Autonomous substitute applied | None invented. Every card and the panel show the year as an open gap with this entry's id. The layer is a flat mark over the picture and a list, never an object of the scene, so no year is needed to keep the 1863 scene true. |
| Strongest evidence-based reconstruction | Per memorial: the year from the NPS inventory chronology line (or the state commission's dedication volume) that names exactly that memorial, with page and quotation, tier documented for the year only. Entries with no such line keep the open gap. |
| Confidence tier | open gap (year); inferred (that every entry is later than July 1863, by what it is and by the Bachelder passage) |
| Competing values | - |
| Product marking | Open-gap pill on every card ("Put up"), the sentence in the panel, the layer's inferred pill, the "Post-battle" pill; the layer notice on the picture says "Put up after the battle: not part of the 1863 scene". |
| Visual and audio impact | None on the 1863 scene (off by default; flat marks only). |

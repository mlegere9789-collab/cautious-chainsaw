# Battle Theatre render prototype (placeholder assets, real ground)

A thin, separate page: 165,000 individually animated soldiers (92,686 Union, 72,314 Confederate; 12,000 of them mounted with 12,000 horses), 360 guns in 60 six-gun batteries with 2,880 crew, on the real USGS 3DEP bare-earth terrain with the USDA NAIP aerial as colour, with a free-fly camera. The positions are **Modelled placeholders** (two fronts, reserve columns, cavalry blocks), not the 1863 positions; the ground is **modern** (NAIP 2022, 3DEP): not the 1863 landscape. Every character, horse and gun is generated by `src/characters.mjs` (no third-party asset is used or downloaded), and the clips are hand-written analytic cycles, not motion capture. What the prototype is for: the performance numbers and the gate harness in `../PLAN.md`.

## Run

```
node docs/battle-theatre/render/prototype/tools/serve.mjs docs/battle-theatre/render 10740     # any static server works
open http://127.0.0.1:10740/prototype/index.html                   # Chrome, WebGPU; ?api=webgl2 for the WebGL2 path
```

Controls: `WASD` move, `Q/E` down/up, `Shift` fast, drag = look, wheel = speed, `1..7` camera presets (overview, ridge, line, battery, cavalry, ground, wide), `F1` HUD, `Space` pause. Query: `api=webgpu|webgl2`, `shot=`, `w=&h=&dpr=`, `nearQ=` (near mesh quality, 1 = 2.9k tris, 2 = 9k, 3 = 19k), `midQ=`, `nearR=&midR=` (LOD radii in metres), `mid=vat|bones` (WebGPU), `fxAlpha=`, `gunRate=`, `f_<pass>=0` to disable a pass (`f_particles=0&f_shadows=0&f_far=0&f_mid=0&f_near=0&f_guns=0&f_terrain=0&f_post=0&f_bloom=0&f_dof=1&f_mblur=1`).

## What is in it

| File | What |
|---|---|
| `src/world.mjs` | terrain loader, deterministic scene of 165,000 soldiers in about 1,000 units, guns, scripted casualties; the CPU mirror of the shader placement/clip selection |
| `src/characters.mjs` | rigs (18-bone soldier, 27-bone horse and rider), procedural meshes at any quality, analytic clips, FK, vertex-animation-texture bake, baked bone matrices, software-rasterised impostor atlas |
| `src/webgpu.mjs`, `src/shaders.mjs` | WebGPU renderer: unit-driven GPU placement, near skinned / mid VAT-or-bones / far impostor LODs, 2 shadow cascades, GGX shading, stateless particles, bloom + DOF + motion blur + ACES, per-pass timestamp queries |
| `src/webgl2.mjs` | the same scene and passes in WebGL2 (data in float textures, depth blit for soft particles, EXT_disjoint_timer_query) |
| `src/lod.mjs`, `src/fx.mjs`, `src/camera.mjs`, `src/main.mjs` | CPU LOD selection, gun/impact/musket events, free-fly camera, page and `window.bench` API |
| `compute.html` | GPU compute microbenchmarks: LOD cull+bin, pose blend + FK, spring bones |
| `tools/` | `build-terrain.py` (3DEP + NAIP to `data/`), `run-bench.mjs` + `run-all.sh` (every measurement), `run-compute.mjs`, `gait-test.mjs`, `anim-tests.mjs` (CPU gate harness), `shots.mjs`, `summarize.mjs`, `make-tables.mjs` |
| `data/` | `height.bin` (1536 x 1536 uint16, 4 m), `aerial.jpg` (2048 x 2048), `terrain.json` |

Sources of the ground (both public domain): USGS 3D Elevation Program bare-earth DEM and USDA NAIP aerial photography (24 April to 10 May 2022) through the USGS National Map, as prepared in `docs/pitch/anim2/basemap`.

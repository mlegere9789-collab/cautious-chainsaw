# Browser verification list: the added layers and panels (the loader, the More tool, the scene hook)

What has been run, and on what, is written in `EXT-CONTRACT.md` section 12 (node tests; the browser harnesses on software rendering in a headless Chromium). **Nothing in this list has been run on a real GPU, in another browser engine, with a screen reader or on a phone.** Each row is owed until a dated line in `GOVERNANCE/progress.md` says it was run and what came out.

| id | check | how | pass |
|---|---|---|---|
| EXT-A1 | The loader in the shell as a viewer gets it: figures, structures and effects drawn, the real `src/ext/index.mjs` and its modules, then Back and a second entry | `tools/horde/bench.sh node app/tests/ext-loader-browser.mjs <outDir> full` (it walks only the stand-in visit and the second entry; software rendering takes very long, so run it where a GPU is) | every check passes, no console warning, `btApp.ext.status()` lists each module `running`, `btApp.perf().phases.ext` stays small next to `render` |
| EXT-A2 | The scene hook (`host.addSceneHook`) on a real GPU, on WebGL2 and on WebGPU | `app/tests/ext-loader-hook-browser.mjs` draws on software adapters only (SwiftShader); a variant that takes the real canvas of a real GPU, like the `--real-gpu` mode of `weather3d-gpu.mjs`, is not built | the six pictures and the checks of the harness hold: the weather pass fogs the far quad, smoke in front of it covers it, smoke behind the near quad does not, the hook is called before the weather pass and the effects pass in every frame; the pictures are looked at |
| EXT-A3 | Firefox and Safari (WebKit): `import('./ext/' + path)`, the one `HEAD` request for the list, the More drawer, the switches, Back and a second entry | the harness `light` mode with those engines, or by hand | modules start, no console error beyond the browser's own line for a missing list, Back leaves nothing in the page |
| EXT-B1 | Screen reader: the More tool (its name says how many parts are not running), the drawer title, each switch (name and state), the announcements "`<title>` shown." and "`<title>` hidden.", Escape returning the focus to the More tool | VoiceOver (macOS and iOS), NVDA, TalkBack | each is read as described, in the order of the drawer |
| EXT-B2 | Keyboard only | Tab to the More tool (it is absent from the order while nothing is registered or failed), Enter, Tab through the switches and the list of panels, Space on a switch, Enter on a panel, the back button of an added panel, Escape | every control is reachable and shows focus; the focus never lands on a hidden element; a redraw of the drawer keeps the focus where it was |
| EXT-B3 | A phone-sized screen with touch | the More tool, a switch, a panel, the list, the Views block "More layers" | all reachable, no horizontal scroll, every tap target at least 44 px, the drawer does not hide the controls the viewer needs next |

# Battle Theatre figure models (FIGURES part of the BT visuals brief)

Written 2026-10-31. Code, data and node tests only: no browser, GPU, Playwright or site build was run (a Release 1 acceptance run was timing the machine). Nothing here has been seen on a GPU. The meshes were looked at through a software rasteriser (`src/figures3d/raster.mjs`, orthographic, flat colours): that checks shape and proportion, not shading or look in the product.

## 2. Figure family

* **Close (LOD0), median 10,256 triangles per man (8,760 to 11,754)**: head with face (2,552 tris skin + 1,192 detail: eyes with iris and pupil, lid rims, brows, ears, mouth slit with cavity and upper/lower teeth rows, jaw bone opens the slit for tearing the cartridge and for commands), 24 head shapes, 8 hair styles, 7 facial-hair types (clean-shaven, moustache, goatee, full beard, mutton chops, chin curtain, burnsides), 12 skin tones by tint, hands with 2-bone fingers and thumbs, 9 coat cuts (sack, frock single/double, short jacket, CS shell jacket, Zouave, six-button tunic, civilian, shirt for coat-off) with buttons, collars, straps, trim, 4 trouser cuts (straight, loose, baggy, chasseur) with stripe and reinforced-seat options, 6 footwear kinds (brogan, worn, tall boot, barefoot, gaiter, legging), 11 hat kinds (kepi, forage cap, Hardee with pinned brim, feather and eagle, slouch, straw, fez, turban, Garibaldi hat, plain cap, Irish sprig, deer-tail), corps badges (8 shapes), rank marks, 16 accoutrement classes (belt with plate, cartridge box with optional sling, cap pouch, bayonet scabbard, canteen, haversack, knapsack with roll or Berdan fur, horse-collar blanket roll, gum blanket, cup, sashes, poncho, overcoat roll, shelter half, tools, cavalry belt set), the arm of the man's weapon record at its record length (barrel/overall inches from `kit/weapons.json`, bayonet fixed or in scabbard), sabres/swords with scabbards, revolvers with holster, drum/fife/bugle/wigwag/stretcher, staff with 34-star national colour, regimental gap colour, Irish green gap flag, ANV battle flag (intact/torn) or guidon.
* **Body**: 12 body shapes (4 builds x 3 chest classes) as 4 shape keys (lean, stocky, narrow, broad) stored as int16 position deltas on every body-conforming part (coats, trousers, footwear, rank marks, strap-bearing gear) at LOD0 and LOD1; stature scale 0.95 to 1.06 per man on the instance.
* **Mid (LOD1)**: parts-sum median about 1,290 (max 1,612 merged; 2,152 worst parts-sum with every accessory); merged per silhouette class on the 36-bone mid skeleton, a separate accessory mesh (22 classes) so the class count stays bounded. **Low (LOD2)**: median 460, max 696.
* **Far**: baked impostor atlas, 8 orientation views of 48 x 64 px per class (view yaw 0..315 degrees in 45 degree steps, material id + view normal + baked shade per pixel; colour from the variant palette), rendered by the deterministic software rasteriser. Pose: rest pose (order arms). ANIMATION bakes frames per clip with `bakeImpostor`. The flag cloth bakes as FLAG_WHITE; `flag-mean-colours.json` gives the colour to substitute.
* **Horse**: riding (2,478 / 646 / 354 tris) with McClellan saddle, blanket, stirrups, saddle bags, lariat, bridle and reins; draught variant with collar and traces. **Guns**: tube by piece id from the kit piece table (6-pdr, Napoleon, 12-/24-pdr and mountain howitzer, 10-/20-pdr Parrott, 3-inch rifle, James, Whitworth; Blakely, 3-inch Navy and Ames Napoleon as GAP-coloured generics), carriage with 14-spoke wheels (976 + 1,240 tris LOD0), limber (1,128), caisson (1,128), rammer and handspike.

## 3. Interfaces

```js
import { createFigureSystem } from './src/figures3d/index.mjs';
const sys = createFigureSystem();
const rec = sys.instanceFromHistory(L.figures, unitId, k, tMin, scenario /*, variantName for a disputed unit */);   // null before arrival; throws for a disputed unit without a variant name (no default chosen)
const words = sys.pack([rec, ...]);             // Uint32Array, 4 words = 16 bytes per figure
const rows  = sys.variantRows();                // Uint8Array, 80 bytes per outfit variant
```
Instance record (documented in `variants.mjs`): w0 kit_variant u16 + accoutrement mask u16; w1 head, body shape, skin tone, hair (style 3 bits, colour 3, grey 2); w2 facial hair + eye colour, stature, wear level (the manifest's wear level), tint (value, warm); w3 flags (flag-bearer, colour guard, coat off, officer, musician, mounted-capable, captured item, gap item), role, LOD hint. All identity fields are drawn from the manifest seed (`hash4`); no `Math.random`. The existing variation scalar (`figures.vari`) keeps working; this record adds the rest.

Variant row (`catalog.mjs`): 3 class indices (mid, accessory, impostor), 9 catalogue indices (hat, coat, trousers, foot, arm, sword, handgun, badge, instrument/flag cloth), role, rank, flag kind, bayonet, army, branch, gap-item count, 14 variant-slot RGB colours. `resolveColours` is the CPU reference of the shader's colour resolution (variant slots, skin, hair, eyes, wear, dust, rain, tint).

Hook points: ANIMATION reads `skeleton.json` (rest = A-pose; poses are local quaternions relative to rest; prop bones re-parent per frame; `prop_long` frame has the rifle sockets; `muzzle` in `parts.json -> meta.sockets` and `gun.pieces` meta gives the FX emitter point). FX: the muzzle position is the animated `prop_long` origin plus the muzzle socket offset; gun tubes have `muzzle_z_m` and `vent_z_m`. Flag cloth vertices carry a wave weight (vertex flag byte 0 at the hoist to 255 at the fly) for the wind pass.

Not wired: the renderer, `world-from-units.mjs` and `src/history/*` were not edited (parallel agents, no browser). The integration step is to call `instanceFromHistory` where `layer.figureVari` is called today and upload `pack()` and `variantRows()`.

## 4. Evidence rules applied

The kit manifest decides WHAT a man carries and wears and keeps its tier; the figures only draw it. Barred items map to a GAP-coloured generic (a leak would be visible; the tests assert none is ever drawn). Gap-placeholder items (Union cavalry boots, unspecified shirts, Zouave 140th NY variant items) are drawn in the GAP colour and counted per variant (instance flag bit 7). Flags: the national colour has 34 stars (tier inferred, statutory reasoning from memory, lookup NOT performed: EG-FIG-0002); the regimental colour is a hatched gap flag (EG-FIG-0003); the Confederate flag is the documented ANV type with 12 stars as the PDF page 70 prints (plausible-procedural, EG-FIG-0005). No regimental colour, face of a named man, or quote was invented.

### 9.2 Hand-over (G4) and the radius rule, MEASURED on the rasteriser
`tools/figures3d-handover.mjs` -> `data/figures3d/handover.json` (6 men x 2 views, 15 distances, 1080p, ppm = 935 / d, 2 x 2 supersample; silhouette error = XOR area / perimeter, L* = step of the flat-shaded mean). The merged mid and low meshes now carry the four body shape keys (`composeMerged` deltas; `shape.mjs`), the mid classes were split (Zouave jacket, chasseur trousers) and the drum/fife/bugle/stretcher, hair and the accessory set were added to LOD1/LOD2: before these fixes the first measurement showed 12 px and 7 L* (a missing drum, wrong trousers).
Result: LOD0 -> LOD1 meets 0.5 px and 2 L* from **10 m** (0.44 px, 1.3 L*); LOD1 -> LOD2 from **13 m** (0.44 px, 1.2 L*); LOD2 -> impostor: silhouette 0.44 px from **75 m**, but the L* step is 1.5 to 3.5 beyond 40 m (above the gate at 55-100 m): per-class brightness normalisation of the baked shade is OPEN. The 48 x 64 atlas has a 31 mm texel; 96 x 128 would roughly halve the silhouette distance at 4 x the bytes. The numbers include the class-representative mismatch.
Radius rule (1080p): LOD0 d < 10 m, LOD1 10-13 m, LOD2 13-75 m, impostor beyond, 15 percent dithered cross-fade, 10 percent hysteresis; scale by vertical pixels / 1080 at other resolutions.

### 9.3 Cost model for 125,000 figures (`cost-model.json`, MODELLED from the measured slopes, not a measurement of these meshes)
Honest answer: **yes for the seven prototype shots rescaled to the measured radii** (all under 16.7 ms: wide 5.6, ridge 6.5, ground 6.4, battery 7.0, cavalry 6.0, line 14.9 versus 16.7 measured with the prototype meshes; the rescaling assumes uniform density and is optimistic along a line), **no for the worst case**, a dense formation (1.8 men per m2) filling the view from 3 m: 169 LOD0 + 128 LOD1 + 10,115 LOD2 figures = 13.3 M triangles = **13.9 ms of figures against the 7 ms allowance** on the Arc iGPU, **54.8 ms on WebGL2**. Only 21 LOD0 figures fit the 7 ms on WebGPU (equal radius 4.5 m in a dense formation) and none on WebGL2.
WebGL2 rule: the LOD0 disc is a triangle BUDGET (nearest figures first, B0 = (7 ms - mid and far cost) / 4.5 ms per Mtri, from a GPU histogram of figure distances in 1 m bins), not a radius; in the dense view the bias below applies with b = 0.36 (WebGPU 0.68). Adaptive LOD-bias controller (spec in `cost-model.json` -> `adaptive_lod_bias`): b in [0.25, 1] multiplies every hand-over distance; e = (t_fig - 7) / 7; b <- clamp(b - 0.35 e - 0.05 integral(e), 0.25, 1), at most 2 percent per frame, dead band 5 percent, recovery 0.5 percent per frame; the LOD0 radius is cut first, then the LOD1/LOD2 swap by sqrt(b), then the impostor swap by b^(1/3), then the resolution scale; the figure count is never reduced. G4 holds only at b = 1 (silhouette error at swap 0.5 / b px); below that the swap is cross-faded and the gate is NOT met: stated, not hidden.

### 9.4 Material maps (`texmaps.mjs`, `data/figures3d/texmaps.json`, `texmaps-preview.png`)
17 tileable 256 x 256 layers generated in code, two RGBA8 maps each (NR: normal xy, roughness, cavity; AM: albedo modulation, micro tint, WEAR mask, DIRT mask), 9 mips with Toksvig roughness, one texture array: 11.3 MB raw, 2.83 MB BC7 (budget 16 / 4 MB). Layers: wool twill, flannel, jean cloth (Confederate army override), canvas, leather, brass, steel/iron, wood grain, skin pores (with a stubble rule for 35 percent of clean-shaven men), hair strands, felt, gum rubber, horse coat, hoof, cotton, bunting, carriage paint. The wear mask is histogram-flattened so a texel is worn where B < wear_level x 255 (the manifest's wear level) and dirty where A < dirt_level x 255; a test checks monotone coverage. `MATERIAL_MAP` maps every material slot to a layer, tile size and strengths; the flag pattern textures stay their own images. Tier plausible-procedural (F-TEXMAPS). Not yet sampled by any shader.

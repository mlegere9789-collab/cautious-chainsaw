## 1. What this baseline means

The legacy tree is frozen and is known to be defective (chapter 13). This report does not say the data is acceptable; it records **today's known violations** so that CI can fail on any *new* violation, on any baseline entry that no longer occurs (a fix must delete exactly its entry), and on entries past their expiry. `E` rules fail the build on a new violation; `W` rules warn (`--strict` makes them fail). A rule that could not run is listed as SKIPPED and is never counted as clean: the ratchet FAILS on a non-deferred rule whose input is missing and on any baselined rule that did not run.

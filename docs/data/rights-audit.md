## Tier tags used

| Tag | Meaning (register / hist-sources-2 section 3) |
|---|---|
| A | public domain, CC0 or notice-only: may be ingested and redistributed |
| B | reusable with attribution and/or share-alike (Wikipedia CC BY-SA 4.0, OSM ODbL): separate files, per-record licence and an attribution surface |
| C | link-out only: never fetch, store, embed or feed to a model (Stone Sentinels, HMDB bulk, ABT, Ancestry family, ACHS) |
| A-pending | believed public, needs written confirmation |
| legacy | shipped before the gate existed; passes rule L001 only after it is listed here with a decided action (until DG-3) |
| claimed_only | a citation string nobody has checked against the source (chapter 13 section 2.4) |
| claimed_book | a copyrighted book named as a source: facts-only, bibliographic citation, never its tables or wording |

## 2. Busey and Martin dependency

Busey and Martin, *Regimental Strengths and Losses at Gettysburg*, is named as a source in 11 OOB files (chapter 13: 11) and 2 other data files, in three spellings. The per-regiment figures the site shows (strength, casualties, casualty_percentage) are that book's core table content. 399 regiment/battery records sit in files that claim it; a further 171 Confederate regiment records sit in three files that declare **no source at all**. Chapter 13 (hist-sources-1-04): no public-domain source exists for Confederate regimental strength, so those figures stay B&M-derived, attributed, facts-only and `estimated`. The register default (Q-DATA-3, owner decision pending): B&M as facts-only with attribution; the open dataset excludes B&M-derived per-regiment numbers and positions until counsel clears them (D-LEGAL step 3).

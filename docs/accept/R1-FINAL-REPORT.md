## Why check 5 is not green

Root cause measured: Mapbox GL's own tasks on a 4x CPU phone (library evaluation, map constructor about 64 ms, style load and first render 130 to 160 ms, load handler about 120 ms) plus the app and ANIM start-up. The published build measures about 210 ms on `/` and also exceeds the limit. Changes made cut about 55 ms and the first-paint flip; what remains needs a lighter map style or a later map start, which changes what a first-time visitor sees. That is the owner's decision. `/ground-remembers` sits at 200 to 220 ms; B11 would need a sliced solve in the animation engine.

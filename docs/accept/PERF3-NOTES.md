- 11:3x FOUND AND FIXED A REAL LEAK in the ANIM tree (item 4): c5 soak of the control (ANIM, no PERF) said "dom-node-growth: DOM nodes 1657 -> 2535 (+53 %) in 300 s" and the same on the PERF3 tree (1662 -> 2540). tmp/perf2/soak.mjs, 300 s of 4x playback: ctl0 (ANIM) nodes 1542 -> 6607, listeners 315 -> 723, heap 19 -> 24 MB; noanim0 (no ANIM) nodes 980 -> 935-983, listeners 274-279 flat. Heap snapshot diff: +294 `<button aria-label="Close">`, +447 Text, +696 ElementAnimations ... = dropped event cards. Cause: ANIM host/popups.mjs `P.spots = new Map()` keyed by the card ELEMENT (placement state per card); the app makes a new card element for every event and drops the old one; the Map kept every one with its listeners (+17 nodes, +1.4 listeners a second). Fix: `new WeakMap()`. After it (tmp/perf3/all5, soak-all5.log): nodes 1057-1123, listeners 275-280 flat over 300 s, heap 23-25.7 MB. T0-P3-13 (100 s of 4x playback, DOM nodes and listeners within +15 %) is green on the fix and red on ctl0 (1531 -> 2722). Not caused by PERF2 or PERF3; it was in ANIM from the beginning and hid behind the soak's heap-only reading in the ANIM tests (B11 reads the heap, not the DOM).

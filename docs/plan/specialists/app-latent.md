### Missed issues (in scope, not listed by the specialist)

1. HIGH - Artillery batteries are invisible to Ask the Historian, Search, Regimental Biography, Battle Reports and Find Ancestor. The OOB holds 103 battery records (95 in union_artillery.json/confederate_artillery.json + 8 horse artillery) but these five pages fetch only the 8 regiment-bearing files and read `.regiments` (historian.html:66-71; zero references to union_artillery/confederate_artillery in those pages). U-ART-D5US (Hazlett's) and U-ART-A4US (Cushing's) exist in the OOB; simulated "Hazlett" returns only the terrain entry. Fix: reuse the main app's iF flattening (corps_artillery_brigades, artillery_reserve, first/second/third_corps_artillery -> battalions -> batteries, horse_artillery) in a shared loader; effort S-M. Directly relevant to the database-expansion plan.
2. MEDIUM-HIGH - Trails canvas (default ON) is stuck at 300x150 px, so ~92% of trail segments are drawn off-canvas. `so` is created at map load (J4 :97260) after the ResizeObserver's first callback already ran K4 (:97274), and K4 returns early when `so` is null (:96709). Live: canvas z=8 is 300x150 (cw 300, ch 150); after 6 s of 8x playback 9 of 120 trail lineTo calls were inside the canvas, 111 outside. Trails only appear in the top-left corner until a window resize. Fix: size `so` inside J4 from the container, resize on map 'resize'; effort S.
3. MEDIUM - Overlay unit canvas ignores devicePixelRatio: no devicePixelRatio anywhere in app code; live at DPR 2 the Mapbox canvas is 2880x1704 but the unit canvas is 1440x852 (desktop) and 375x812 (mobile), so unit sprites/labels are upscaled 2x and blurry on Retina/phones. Fix: backing store = css size x dpr + ctx.setTransform; combine with -07; effort S-M.
4. MEDIUM - Sequencing/dependency gap: -04 (enable pan/zoom) depends on -07 (redraw on move) and on rewiring `_gbDist`; shipping -04 alone makes units float during user pans and breaks the Distance tool.
5. HIGH (planning) - Effort estimates for app-bundle fixes (-02, -04..-10, -17..-21, -28) assume editable source, but the only source is a minified bundle (BRIEF N1; RECON_SRC is v21 on mapbox-gl 2.15 without Sound). Only the immediate patches in -01/-03 are realistically regex-patchable. Add an explicit gate: -43 (source recovery, XL) precedes the M/L app fixes; otherwise the plan repeats the regex-patch workflow that created these bugs.
6. LOW - The mobile map has no maxBounds (desktop has [[-77.36,39.72],[-77.12,39.91]]; mobile options at :102975-102988 have none). Once touch pan is restored (-04/-06) users can pan away from the battlefield; add the same maxBounds.

## 4. Reconciled design decisions (binding for the specs)

1. **Breakpoints (D-SHELL).** `compact` = `(max-width:834px), (max-height:480px) and (pointer:coarse)`, else `full`; 768-834 (iPad 9.7/10.2/Air/Pro 11 portrait) = compact with side sheets, 835+ = full with 44 px coarse targets. Re-evaluated on `change`, never remounts the map; shell switch by `@media`, component internals by container queries.
2. **z-scale (D-SHELL):** app-design's (tokens 5.1); app-mobile's smaller scale is dropped. **Tokens:** app-design 3.2-3.4 is authoritative; app-mobile `--ink*` and app-a11y `--text-*` survive only as migration aliases; type ramp app-design (12 px floor, 16 px body).
3. **Focus ring** two-tone everywhere: 2px `--focus-ring` + offset 2 + 4px `--focus-halo` (>= 4.58:1 on any background [S app-a11y 5.1]); gold marks selection, never focus.
4. **Sides** (one decision, owner decision O-5 of chapter 07, DG-3): today's `#3a6bc4`/`#c43a3a` are hue-safe (dE2000 41.7-65.8) but equal in luminance (1.02:1 [S app-a11y]; `#6fb1ff`/`#b3261e` is 2.93:1 [V]), so a non-colour cue always ships: notched, hatched Confederate frame, "U"/"C" label prefix, the word in every list. Which palette is the default is O-5's (chapter 07 default: the luminance-separated pair `#6fb1ff`/`#b3261e` + hatch; alternative: today's hues); the other palette is the Settings "High-contrast sides" option, and WP-20 draws whichever `symbology.json` names.
5. **Chrome budget.** `/map` compact = header 52 + dock 100 (+ insets) so the map stays >= 73%; NO persistent bottom tab bar on `/map` (a 56 px bar would drop a 667 px phone to 69%, 57% with insets); the five destinations lead the header Menu sheet; content pages (Stories, Find, Ask, Visit) show the 56 px bottom tab bar.
6. **Header.** Full: wordmark, Battle/Stories/Find/Ask/Visit, palette field, Share, More; Ask = accent-outline pill. Compact: time block (opens Timeline sheet), Search 44, Ask 44 (label >= 360 px), Menu 44.
7. **Docks (full).** One docked panel below 1920 px, two at >= 1920 px; rail 56 px (72 with 12 px labels at >= 1280).
8. **Entry.** The 20-second moment starts only after a gesture (D-ENTRY item 4), is skipped under reduced motion/data-saver/2G, shows no clock text until D-TIME is signed.
9. **Keys.** Slider Home/End = first/last step; `1/2/3` = frame that day; `[ ]` previous/next moment; `,` `.` step; `code`-first matching (D-LANG).
10. **Vocabulary.** "Moment" = curated entry (24 vignettes, 137 events); "step" = one of 675 frames (tooltips/debug only); clock from the single formatter; never "tick" or "real time". Speed = "1x" + a description generated from the time model at the current step: a fixed "10 min/s" is only nominal under D-TIME's 0.83-42.3 min/step warp [U].
11. **Renderer (D-UNIT-RENDER):** owned Canvas2D `UnitRenderer`, symbol layers only if gate G-R fails. **Derived images (D-MEDIA):** own vector basemap.
12. **Route (D-ROOT).** The app lives at `/` until train S3 (latest 2027-01-26) and at `/map` afterwards; every `/map` criterion, screen and test in this chapter means `/` before S3 and `/next/` during the rebuild, and all links come from the one route constant `APP_PATH` (the same constant as in chapters 08a/08b/12).

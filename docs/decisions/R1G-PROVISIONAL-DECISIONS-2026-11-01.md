# Release 1 (train R1g): decisions taken without the owner, 2026-11-01

The owner's order stands: ask nothing, take the conservative decision, log it with the way back. None of these lowers a gate or a limit. Items from the other agents of the round are appended by them below their own heading.

## ZSTAT (static and test defects that the R1f pack called "identical on R1e": static.overlap, static.legal, r1.clock CLK-03/06, T0-DL-10, T0-VMON-05)

None of them is a defect of the shipped bytes. Each was a defect of the check: the check is now exact, red-first where it can be, and no bundle patch is needed (no PG-zstat group exists).

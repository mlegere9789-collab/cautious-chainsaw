Changelog

Last reviewed: October 4, 2026. Status: candidate.

What has changed, in sentences a visitor can use. Nothing below has been released yet: it describes release trains R0 to R1c, which are built and tested and waiting for the owner.

Status of release R1c: built and tested locally; not deployed. The live site is still the build of September 30, 2026. Version numbers are not assigned yet; the project’s plan proposes calendar versions such as 2026.11.0, which have not been adopted.

Next release (R0 to R1c)

Added

  • A phone layout, chosen automatically on phones and touch tablets up to 834 px wide and on phones held sideways. The address ending ?layout=mobile or ?layout=desktop forces one.
  • Accessibility changes to the map page: a skip link, one main heading, landmarks, labelled controls, a timeline that works as a slider with its value in words, and dialogs that keep keyboard focus. These are a bridge, not a claim of conformance.
  • Share links: the map reads moment, day, unit, story, regiment, zoom and centre from the address and opens there.
  • A Help row for moving the map from the keyboard (release R1c), and Help text for the phone layout (release R1b).

Changed

  • The 3.5-second introduction is gone: the map appears at once.
  • Dates read July 1, 2 and 3 instead of dates up to July 9.
  • A press on the map no longer leaves keyboard focus on it, so the arrow keys step through time after a click or a drag. Space no longer starts the playback while a toolbar button has focus, and S no longer types an “s”.
  • Help wording: the speed label reads 1x (base speed) and no longer implies that the map plays at the pace of the battle, the Help panel says hundreds of regiments and batteries instead of 445+, and its list of works is headed Sources.
  • Turning Points links now land on the moment each decision belongs to.

Fixed

  • The map can be dragged and zoomed with a mouse again.
  • Jumping to a day loads that day’s positions, and the map shows each unit at its latest recorded position at any moment.
  • Several pages no longer print a code word where text belongs: the dashboard, the unit reports and Ask the Historian.
  • Watch Together no longer shows imported tour text as page markup.
  • The Casualty Dashboard no longer shows a note meant for the developer.
  • Map attribution is no longer hidden under the playback bar on desktop.

Removed

  • The heatmap key and its Help row, and the sound button inside the map. Immersive Mode is the page that plays sound.
  • Battlefield AR is no longer listed in the menus or the sitemap and is hidden from search engines while it is tested.
  • Two developer pages are deleted from the site.

Data

The data is at version 0.9.0: the 71 files of the September 9, 2026 deploy, unchanged by the release trains, which do not edit data files. One file differs on the live site from that baseline: the terrain file, which production corrected after the deploy. Release R1c adds one new file, a list that turns a story id into its moment, used by share links.

Known issues in release R1c

  • The Help panel and some pages still say tick and five minutes, and call 12 moments one hour. Moments are not five minutes apart everywhere; read the moment as a place in the story, not a fixed length of time.
  • Clock labels can be hours off in places. Release R1c changes only the date (July 1, 2 and 3 instead of dates up to July 9); the clock itself is waiting on a decision about the time model.
  • The Monuments button is in the toolbar, but it shows nothing in this release. The star layer that appeared when it was pressed was removed from the site in production, and restoring it properly is on the owner’s list.
  • The heatmap key and the in-map sound switch were removed in release R1a. Immersive Mode is the page that plays sound.
  • Some labels on screen use older names, for example the menu is called Extra Features and one page is called Battle Reports. This guide uses the names the style guide settles on and gives the on-screen label beside the first mention.
  • Ask the Historian searches this site’s records. The count shown on its page is computed from the loaded files.
  • Everything in this guide was checked against the release’s text, key handler and tests. Release R1c has been run only in Chrome on a desktop computer (touch was emulated). Safari, Firefox, Samsung Internet and real phones have not been tested.

Earlier

No earlier changelog exists. Versions of the site before release R0 are not described here.

Accessibility Statement

Last reviewed: October 4, 2026. Status: candidate.

The Gettysburg Interactive Map has not been evaluated against the Web Content Accessibility Guidelines, and no level of conformance is claimed. This page says what has been tested, what the results were, and what is known to be missing.

Status

The work so far is a bridge. Release trains R0 to R1c change the existing built site with scripted, checked patches; a full rebuild is planned and has not started. Release R1c is built and tested and has not been released: the live site is the build of September 30, 2026, which fails the same tests (see below).

Automated tools find only part of the barriers a person meets. A passing automated test is not a statement that the site is accessible.

Known gaps, and what to do instead

  • No screen reader test is on record. No test with NVDA, JAWS, VoiceOver or TalkBack is in the project’s records. [OWNER TO CONFIRM: whether any manual test with a screen reader was done, and by whom]
  • The battlefield is drawn on a canvas. Units are not announced one by one. A keyboard user can pick a unit through Search (Enter in the field, Down arrow into the list, Enter on a result) and read its details panel. A text or table view of the whole battlefield is part of the planned rebuild and does not exist yet.
  • The clock. Clock labels can be hours off. Read the moment as a place in the story and use the story text for the order of events.
  • Colour. The eleven states of a unit are told apart by colour. The audit that preceded this work found that the legend colours do not all match the colours drawn on the map; that audit finding has not been re-measured here.
  • Motion. The playback is an animation. Space pauses it, and the speed keys slow it down.
  • Other people’s content. Street View opens in Google Maps in a new tab and is Google’s content. Captions of National Park Service videos have not been checked.
  • The user guide. A candidate guide is built as a tagged PDF and as a web page. Only this project’s own checks have been run on the PDF; no independent PDF accessibility check has.
  • Language. The site is in English only.

# english-seed.v1.txt - common modern English words, written by hand for the Historian's typo repair (one or more words per line, '#' starts a comment).
# Purpose: a question word that is ordinary English is never "corrected" into a name ("fraction" is not "action", "list" is not "last", "alley" is not "Allen").
# This is a dictionary of words a reader might type in a question about history; it carries no names, no site text and nothing from any catalogued source.
# Regular inflections (plural, -ed, -ing, -ly, -er, -est) are covered by the matcher in core/english.js, so only base forms are listed here.
# Merged at build time with english-period.v1.txt (words found in public-domain 1863 reports, see gen-english.mjs) into facts.english.

# Tranche-0 tooling and release content: change log

Scope: `tools/t0/` (build system, patch groups, overlay, config generator), `tests/t0/` (harness and suites), `ops/` (runbooks, probes) as they
stand at the integration commit of 2026-09-30. Nothing here has been deployed. Plan: `docs/plan/FINAL/02-tranche0-hotfix-runbook.md`
(chapter 02) and `docs/plan/FINAL/01-decision-register.md`. Per-train release notes: `ops/release-notes/<train>.md`

## 2026-09-30 - integration (train set R0 fb14ab00, R1a 740deb52, R1b 8ad6d7cd, R1c 9feb2ee6)

Built all four trains from scratch (`python tools/t0/build.py --all`), gates green, rebuilt twice into different directories: every file of
every dist is byte-identical (sha256), as are `anchors.json` and `manifest.json` (`tmp`-level comparison; `build_selftest` case 1 proves the
same for R1c on every run). Changes made by the integrator to files owned by the group agents:

1. `tests/t0/build_selftest.py` case 6 (plugin interface): its throwaway `PG-selftest` group deleted `diagnostics.html` and
   `unit-rendering-reference.html`, which the real `PG-core` already deletes ("file to delete does not exist"). It now deletes
   `apple-touch-icon-precomposed.png`, which no real group removes. The case still proves placeholders, delete, overlay new + replace, the
   hook whitelist and four negative cases. `tools/t0/build.py` no longer prints the hard-coded `release/<train>/anchors.json` in its
   anchor-failure message (it prints the real output path).
2. Group EB removed. The AMD-T0-1 error boundary is patch `A-error-boundary` in `A.json` (the owner authorized the full plan); `EB.json` anchored
   on the same text and failed (`expected 1, found 0`). `trains.json` `optional_groups` is now `[]`; `--with GROUP` stays for future use
   (`build.py`, `overlap.py`, README updated).
3. `trains.json` `known_overlaps` now records the four ordered dependencies the overlap audit flagged: AX anchors on group C output
   (`AX-mobile-map-id`, `AX-mobile-dock-id`), CP anchors on group C output (`cp:mobile-tools-footer`), and the adjacent finds `bug:K-skip-tour`
   (A) / `AX-onboarding-dialog` (AX), which share `V.jsx("div",{style:tr.overlay` that A's replacement keeps, so either order matches
   (`build_selftest` case 5 builds both orders and compares the bytes). `python tools/t0/overlap.py` reports 0 unexplained overlaps.
4. `data/moments.json` moved from `overlay/common` (shipped from R1a) to `overlay/R1c`: nothing in R1a/R1b reads it, and the plan files moments
   v0 under R1c (WP-T0-09). R1a and R1b lost one file (124 files each); R1c is unchanged.
5. `tests/t0/mobile-matrix.spec.mjs` T0-MOB-09 (popup over the story cards): the test computed the tick-12 position of U-CAV-1-1 from
   `placements_day1_ticks1_50.json` only. With group B (R1c) the unit is correctly held at its latest keyframe at or before the tick, which is the
   tick-9 row in `density_day1_opening.json`, so the tap missed on R1c while it passed on R1b (bisected by building R1c with each of B, DL, CP
   emptied: only B changes it). The test now tries every keyframe at or before tick 12, latest first. Product code is untouched.
6. `tests/t0/mobile-matrix.spec.mjs` T0-MOB-05 and `tests/t0/r0.mjs` T0-R0-03 counted Chrome's own cache revalidation as a second Mapbox style request: the style JSON is served with
   `Cache-Control: max-age=900, stale-while-revalidate=3600`, so once the copy in the session's HTTP cache has expired Chrome answers the page's fetch
   from the cache and sends one background revalidation (resource type `Other`, about 20 ms later, same frame, same sku). It made MOB-05 fail on R1b
   in two consecutive four-slice runs (different viewports each time; four parallel sessions hit it at the same load number) and never in a
   single-session run. Reproduced with `tmp`-level probes (same two requests in all four sessions, `Fetch` then `Other`, `max-age=900` header seen).
   Both tests now count only the page's own requests (`type !== 'Other'`). A real second map would still show as a second `Fetch` and a second sku.
7. `tools/t0/run_suites.mjs` red-first rules: a red proof needs at least one FAILED test and no skipped one
   (a spec that skips on legacy proves nothing), and specs that assert the red state themselves under `--expect-red` (a11y, copy) are marked `inverted`.
8. New tools: `tools/t0/verify_release.mjs` (independent check of the four trains: manifest, static crawl with no dangling reference, dev pages,
   asset-name ledger across trains, identity invariants of rule 5, cumulative trains, legacy pinned), `tools/t0/run_suites.mjs` (every suite and
   the red-first proofs, one summary JSON), `tools/t0/release_notes.py` (the notes), `package.json` scripts (`t0:verify`, `t0:test:all`, `t0:test:*`,
   `t0:notes`), README and this change log.

## Deviations from chapter 02 (all recorded by the owning agent; none changes the train order or the closed list)

* Group order is `R0 A B DL C AX CP` (chapter 02: `R0 A C AX B DL CP`); `build_selftest` case 5 shows identical shipped bytes.
* Mobile layout query uses 834 px, not 820 px (`mob:HF-5a` note); tablets 744-834 px get the stretched phone shell. One-token change, decide with the device checks (O-T0-9).
* Group counts differ from the runbook (A 25 vs 23, B 13 vs 12, DL 7 vs 1, C 72 vs 53, AX 61 vs 13, CP 20 vs 16 + 3): the extra patches were added by the owning agents while proving their groups in Chrome (for example `B-ancestor-loads-days`, strict DL validation, 44 px targets, axe findings). * DL also resolves `?vignette=`/`?v=` through `moments.json` (the plan deferred it), validates strictly, and Turning Points anchors are path-target patches in `DL.json`.
* HF-3c checks `showUnits` so Toggle Units off blocks selection (T0-IN-03 acceptance), while the Distance tool still gets the click.
* AX: the CSS shim is appended to the app stylesheet and the reduced-motion flag is defined at the top of the entry (no new `a11y-shim.css`/`a11y-flags.js` files); hidden `h1` text is the current product name; Lighthouse was not run (not installed); axe runs with Lighthouse's rule ids instead.
* PG-maps: manifest screenshots kept as own-art title cards instead of deleted; SRI on Mapbox GL and PeerJS (fails closed); 7 CLS-guard patches.
* Config (WP-T0-15): `X-Frame-Options: DENY` + `frame-ancestors 'none'` (runbook: SAMEORIGIN/`'self'`); noindex for staging through `T0_CONTEXT=staging` (Netlify has no per-context headers); `netlify.toml` is comment-only; Permissions-Policy tightened (runbook said no tightening); HTML clean URLs get `no-cache, must-revalidate`; `/*.sql` and `/*.bak` scanner rules dropped (`*` mid-path is invalid); probes HP-10/11/12 are expected-red until S1 (rule 5 forbids URL-form and sitemap changes).
* PG-legal: date is the literal "September 30, 2026"; `[OWNER TO CONFIRM]` markers are HTML comments; ships in R1c by default.
* Ops: release log is `ops/RELEASE-LOG.md` and the runbook `ops/RELEASE-RUNBOOK.md` (plan: `docs/releases.md`, `docs/runbooks/t0-release.md`).
